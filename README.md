# Trello Clone

Trello - kanban dashboard. You can create, edit, and delete boards, cards, and lists.  
Created within the boundaries of the school **Sh++**.

### How to launch the project:

1.Download the repository files and go to the copied repo:
```bash
git clone https://github.com/AnnPoshtak/TrelloClone
cd TrelloClone/Trello
```

2.Install dependencies and run:
```bash
npm install 
npm run dev
```

### Tests

There are several ways to run tests:

Run all tests in console:
```bash
npm run test
```

Run tests with UI (interactive mode in browser):
```bash
npm run test:ui
```

Run tests with coverage report:
```bash
npm run test -- --coverage
```

Run tests with both UI and coverage:
```bash
npm run test -- --ui --coverage
```
